Common questions

The pane says "The checker isn't running"
Wait 30 seconds, then press Try again. If that doesn't help, double-click Arcas.exe again. It asks you to close Excel, repairs the install, starts the checker and opens Excel again. With an invite kit, double-click install.bat in the kit folder instead.
Windows says "Windows protected your PC"
The app is not code-signed yet, so Windows warns about it. Click More info, then Run anyway. Some PCs show "Open File - Security Warning" instead: click Run.
Windows asks to install a certificate
During the install, Windows asks whether to install a certificate from "Anomaly Hunter local CA". Click Yes. It works only for localhost and 127.0.0.1 on this PC, the key that made it is never saved, and uninstall removes it. If you click No, the install stops: run it again and click Yes.
How do I update?
Download the latest Arcas.exe and double-click it. If Excel is open, it asks you to close it first. Your AI key stays. The version you have is the Engine line at the bottom of the pane. With an invite kit, double-click install.bat in a newer kit from John.
How do I uninstall?
Press Windows+R, paste "%LOCALAPPDATA%\AnomalyHunter\Arcas.exe" uninstall and press Enter. It removes the add-in, the checker, its certificate and its files, except the app file itself, which you can then delete. It is not listed in Windows "Installed apps". The Privacy page lists what it removes. With an invite kit, close Excel, run install.bat /u in the kit folder, then delete the kit folder. Like the app's uninstall, it also clears Excel's add-in cache, so other web add-ins may need to be added again.
Where is the log?
In %LOCALAPPDATA%\AnomalyHunter: server.log is this run's, server.log.1 the run before. It can quote values from your sheet, so read it before you paste any of it.
Where is AI help, and what does Remove key do?
Open AI help (optional, free) at the bottom of the pane. Paste a free Google AI key from aistudio.google.com/apikey, or an invite code (it starts with inv_), and click Save key. Then use Ask AI on a flagged row. Remove key deletes the key and invite code saved in your AnomalyHunter folder; scans and fixes keep working. With an invite kit, also delete invite-code.txt from the kit folder, or installing again turns AI help back on.
It flagged a correct value, or missed one
It can flag correct values and miss mistakes. Move the How hard to look slider: lower for fewer, surer flags; higher to look harder. A suggestion changes nothing until you click Accept; Dismiss skips it.
Is my data private?
A scan runs on your PC and sends nothing. Only Ask AI and Check words with AI send part of your sheet: to Google, or through John's relay to Google if you use an invite code. The Privacy page says what is sent.
