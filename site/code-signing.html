Code signing policy

Arcas has applied to the SignPath Foundation's free code signing program for open-source projects. Until the application is accepted and the release build signs the file, Arcas.exe is not code-signed, and Windows may warn about it.

Once accepted
Releases will say: "Free code signing provided by SignPath.io, certificate by SignPath Foundation."
What gets signed
Only Arcas.exe as built by this repository's GitHub Actions workflow (build-exe.yml) from the public source code, after its tests pass, including the install on a fresh Windows PC. Nothing built anywhere else, and no other project's files.
Team roles
Committer and reviewer: John Nguyen. Approver: John Nguyen. Changes from anyone else are reviewed by John before they are merged.
Privacy
This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Privacy & security says what AI help sends when you click it.
