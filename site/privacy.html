In short

  • A scan runs on your PC and sends nothing to the internet.
  • Your sheet's data leaves your PC only when you click Ask AI, Check words with AI or Check subject rules with AI, and then only the part described below.
  • There are no accounts and no cookies, and the add-in has no analytics and no tracking.
  • Only this project's website may count its page views, with GoatCounter (see who else sees something).
  • You can delete your saved AI key with Remove key, and uninstall Arcas from Settings > Apps.

What stays on your PC

The scan

Excel hands your sheet to a small engine on your own PC, at https://127.0.0.1:5055. It checks the sheet in memory and answers the pane. A scan never sends anything to the internet. Before a scan, the pane reads your sheet's header and first 500 rows on your PC to say what the scan will check; it sends nothing to the internet and saves nothing. Find problems also reads the first 5,000 rows of every tab (up to 20) on your PC, to say when two tabs hold the same numbers; it sends nothing to the internet and saves nothing. Check as you work reads the sheet you change on your PC, a moment after you change it, to say when a cell you changed looks wrong, and where your Excel allows it, goes on after you close the pane until you close the workbook; it sends nothing to the internet and saves nothing.

Files in %LOCALAPPDATA%\AnomalyHunter

  • Arcas.exe: a copy of the app, so the engine can start when you log on. An update over an install made before the app was renamed Arcas deletes the old app file; if Windows still holds it, it stays until the next update or uninstall.
  • server.log and server.log.1: the engine's messages and errors. server.log starts empty each time the engine starts, and server.log.1 keeps the run before (each start replaces it). An error message can quote a value from your sheet.
  • ai-cache: up to 500 AI answers, so the same question isn't asked twice. An answer can quote your cells.
  • gemini-key.txt or invite-code.txt: your Google AI key or invite code, if you added one. Each is sealed with Windows' own encryption (DPAPI) for your Windows account, so a copy of the file is no use on another account, though a program running as you could still open it.
  • ca.pem, cert.pem, key.pem: the certificate the engine uses for HTTPS on this PC.
  • addin\manifest.xml: the file that lists Arcas in Excel.
  • Start here.xlsx: the practice workbook.
  • anomaly-hunter.pbids and anomaly-hunter-flags.pbids: shortcuts that open latest-scan.csv and latest-flags.csv in Power BI. They hold only those files' paths.
  • latest-scan.csv: only if you turn on "Save each scan for Power BI" (off unless you turn it on). It holds a plain-text copy of every cell of the last sheet you scanned, with each row's number, result and suggested fix. Each scan replaces it. After you turn the option off, the next scan deletes it.
  • latest-flags.csv: only with the same option on. It holds the sheet's name, the time of the scan, and the number, result, suggested fix and status (Open, Fixed or Dismissed) of each flagged row and each row you fixed or dismissed (results and fixes can quote your cells). It is kept and deleted together with latest-scan.csv.

If you installed a setup kit from John with install.bat

John shares kits by a Google Drive or OneDrive link. A kit runs from its own folder: install.bat downloads the Python packages it needs from PyPI, the Python package site (PyPI sees your IP address), and keeps them in a .venv folder there, with the Power BI shortcuts in its powerbi folder. It saves the kit's invite code in the folder above, sealed like a code you paste. The kit folder keeps its own invite-code.txt as plain text, as John made it. A kit has no Arcas.exe, addin\manifest.xml or Start here.xlsx: Excel lists the add-in from the kit's frontend folder. To uninstall a kit, run install.bat /u, then delete the kit folder. Like the app's uninstall, it also deletes Excel's add-in cache (the Wef folder), so other web add-ins may need to be added again.

Elsewhere on your PC

If you installed Arcas.exe, it unpacks itself into a temporary folder in %TEMP% each time it starts. If the engine is stopped by force, that folder can be left behind. Install removes the "downloaded from the internet" mark from its own copy of the app, so Windows doesn't warn at every logon.

In your workbook

The workbook you scan keeps the limits you changed, the strength slider, a list of the last auto-fixes with their old values and a copy of each fixed row (so Undo works), the old values and number formats of the cells you changed with Accept, and what Accept wrote in them (so Undo still works after the pane is closed and opened again), a short code for each row you fixed or dismissed (worked out from the row's values, never the values themselves, so the row is still Fixed or Dismissed when the pane opens again), a short code for each value you dismissed and the checks you stopped (the column and the kind of check, worked out on your PC, never the values themselves, so the next scan of that sheet, and Check as you work, do not flag them again), the subject rules that held when you clicked Check subject rules with AI (each rule's kind and the column headers it names, never a cell or the AI's words, so every later scan of that sheet checks them on your PC with no AI), the fill colour each highlighted cell had before (so Remove highlights puts it back after the pane is closed and opened again), the numbers of the last check (the sheet's name, when it ran, the slider's level, and how many rows it read and flagged, never a value or a reason, so the pane can say them when the file opens again), and a setting that opens the pane with that file. Highlights are fill colours written into your cells. A fix changes your cells only when you click Accept, or when auto-fix runs, if you turned auto-fix on.

In the pane

The auto-fix switch (anomalyHunterAutoFix) and the Power BI switch (anomalyHunterPowerBi) are saved in Excel's storage for the pane (its localStorage), on this PC. Ask AI's memory (anomalyHunterAiMemory) is saved there too: up to 200 fixes you accepted with Accept, in any workbook, each with its column name, the kind of fix, and the old and new values. Undo takes a fix back out. The two Check as you work switches (anomalyHunterLive and anomalyHunterSound) are saved there too.

What AI help sends

With no key or invite code of your own, AI help uses John's free AI (below). You can also paste a Google AI key or an invite code, or install a setup kit from John (or a developer sets GEMINI_API_KEY on the PC). In every case, nothing from your sheet is sent until you click Ask AI, Check words with AI or Check subject rules with AI.

When you save a Google key, the engine asks Google once whether the key works. That call carries the key and no sheet data. A key from a Google project with billing turned on can be charged by Google for what AI help uses. Without billing, the free tier costs nothing.

  • Ask AI sends the column names, the row you asked about, up to 5 rows above and 5 below it, the formulas in that row, the cell addresses, the reason it was flagged, and anything you type in the request box. On a wide sheet, only the columns nearest the flagged cell and any column your request names go. Long cells are cut to 200 characters, except the flagged cell. Before it goes, emails, phone numbers, US Social Security numbers and card numbers written in their usual forms are swapped on this PC for stand-ins such as [EMAIL_1], and the AI's answer gets the real ones back here. Up to 5 fixes you accepted before in a column with the same name as the flagged one, from Ask AI's memory (each one's column name, the kind of fix, and the old and new values), are sent with Ask AI only once the AI memory is switched on in a later update. Until then they stay on this PC.
  • Check words with AI sends the names of your text columns that have 2 to 50 different values, and those different values, up to 60 characters each. It never sends whole rows or numbers. These values can include names of people or places, and they go as they are: judging a word needs the word itself.
  • Check subject rules with AI sends your column headers (the first 200, each cut to 100 characters) and whether each column holds numbers, dates, text or IDs. It never sends a cell. Arcas checks each rule the AI names on every row on this PC. Headers can include names of people or places. The rules that hold are kept in the workbook, and every later scan of that sheet checks them on this PC without asking the AI.

If what you type to Ask AI reads as someone in crisis, the pane shows helpline numbers instead and sends nothing to the AI.

Where it goes

  • With your own Google key: straight to Google's Gemini API.
  • With your own key or an invite code, Google's main Gemini model (gemini-3.8-flash) answers. With your own Google key, if that model is busy or its free requests for the day are used up, the same request goes to a backup Gemini model (gemini-3.5-flash-lite), also Google's, and the pane says so. With an invite code, only the main model answers.
  • With an invite code: to John's server on Cloudflare, which passes it to Google with John's key. A developer setting on the PC, ANOMALY_HUNTER_RELAY, sends invite calls to another server's https address instead.
  • With no key or invite code of your own: to John's server on Cloudflare, which passes it to Google's gemini-3.5-flash-lite with John's key. That server counts each network's AI calls for the day under a code made from the day and your IP address with the server's secret key, so the code changes every day. It never stores your IP address or the request. It allows 15 AI calls per network and 400 for every free user together a day. It also allows at most 15 calls a minute from one network, and 45 a day from one IPv6 /48 (the block of networks one provider may give one customer).

Google's free tier may use what you send to improve its products. The free AI and invite codes always use John's free key. With your own key, it depends on your Google plan. Don't ask AI about private or personal data.

Who else sees something

  • Google receives what AI help sends, under Google's own terms.
  • With an invite code or the free AI, each AI request passes through John's server on Cloudflare. That server keeps one counter: for the last day anyone used it, how many AI calls each invite made, under the name John gave that invite, plus the total, and for the free AI how many each network made under its daily code, plus their total. The first call of a new day replaces it. It saves no request and no answer, and its saved logs are switched off. The list of invites (a scrambled copy of each code and a name) stays until John removes it. Cloudflare sees your IP address as the request passes. The server's key never reaches your PC.
  • PyPI sees your IP address only if you install a setup kit from John, when install.bat downloads Python packages from it.
  • GitHub hosts the download, so GitHub sees your IP address when you download the app. Anything you post in a GitHub issue is public.
  • The website's contact form and support form send nothing themselves: each opens a public GitHub issue filled in with what you typed, which you submit on GitHub yourself, or, with Email John instead, a new email in your own email app, which you send yourself. The links to John's LinkedIn, Handshake and GitHub profiles are plain links: nothing loads from LinkedIn, Handshake or GitHub until you click one, and then that site's own terms apply.
  • Microsoft: Excel loads Microsoft's Office script from Microsoft for the pane, and Windows may check the downloaded file. Microsoft's privacy terms apply.
  • GoatCounter: this project's website, never the add-in, the pane or the engine, counts its page views with GoatCounter. Each page view sends GoatCounter one request with the page's address on this site and nothing else: no cookie, no referrer, no title, no screen size, and nothing at all under Do Not Track or Global Privacy Control. Like any server, GoatCounter's sees your IP address and browser with that request. GoatCounter's privacy policy says what it keeps.
  • Nothing is sold, and nothing is used for ads or tracking.

Your control

  • Remove key in the pane deletes the key and invite code saved in %LOCALAPPDATA%\AnomalyHunter. Scans and fixes keep working, and AI help goes back to John's free AI, which sends nothing until you click Ask AI, Check words with AI or Check subject rules with AI. A setup kit from John keeps its own copy, and running its install.bat again turns AI help back on, so also delete invite-code.txt from the kit folder. A GEMINI_API_KEY setting on the PC keeps AI help on.
  • To delete the AI cache or the log, delete ai-cache, server.log or server.log.1 in the folder above, or uninstall.
  • Forget what this workbook saved: in the pane, under Options > Saved in this workbook. It removes everything the pane saved in the open workbook: the limits, the strength slider, the auto-fix list with its old values, the old values Accept keeps for Undo, the code of each row you fixed or dismissed, the codes of the values you dismissed and the checks you stopped, the subject rules that held, the colours your highlighted cells had before, the numbers of the last check, and the setting that opens the pane with the file. It changes no cell. Save the workbook afterwards to keep the change in the file.
  • Forget what the AI learned: in the pane, under Options > AI help. It removes every fix Ask AI remembers on this PC, for every workbook. Forget what this workbook saved leaves them, as they are not in the workbook. Uninstalling also removes them with Excel's add-in cache.
  • To uninstall, open Settings > Apps > Installed apps, find Arcas and choose Uninstall. An Arcas installed before November 2026 is listed there after its next update; until then press Windows+R, paste "%LOCALAPPDATA%\AnomalyHunter\Arcas.exe" uninstall and press Enter. It removes the startup entry, its Installed apps entry, the Excel add-in listing, the certificate and the files in that folder, the app file too, a few seconds after it closes. It also deletes Excel's add-in cache (the Wef folder), so other web add-ins may need to be added again and may forget their settings. It never touches your workbooks, so settings a scan saved inside a workbook stay there until you use Forget what this workbook saved in each one.
  • To remove your invite, ask John the way you got it.
  • Data-protection law where you live may give you rights over data about you: to see it (access), correct it (rectification), have it deleted (erasure), limit how it is used (restriction), take it elsewhere (portability) and say no to its use (objection). Almost nothing about you ever reaches John, so for most of these there is nothing to ask for: a scan stays on your PC, this website's counter keeps no name and no cookie, and the relay counts calls under a one-way hash with no IP address in it. What does exist is what you chose to send: a GitHub issue you wrote, which you can edit or delete yourself, and an email or a call you made. To use any of these rights, write to John at john4000.nguyen@gmail.com.
  • Why this is allowed, and how long it lasts: AI help runs on your instruction, each time you click it. This website's visit count rests on John's legitimate interest in knowing how many people come, and you can switch it off for yourself with Do Not Track or Global Privacy Control in your browser. Nothing is kept on a timer because there is almost nothing to keep: the relay holds one number for the last day anyone used it, and your sheet is never stored off your PC at all. If you think John has any of this wrong, you may complain to the data-protection authority where you live.
  • You can edit or delete your own GitHub issue. John can delete it if you ask. Copies made while it was public may remain. John holds no other data about you.

Security

  • The engine answers only on 127.0.0.1, over HTTPS. Install adds a certificate to your Windows account that works only for localhost and 127.0.0.1. The key that made it is never saved, so it can't sign anything else.
  • Websites can't call the engine: it checks where each request comes from. Other programs on this PC can, like any local service.
  • The pane loads only its own files and Microsoft's Office script. Its Content Security Policy blocks everything else. The fonts are on your PC.
  • Install also adds a startup entry, so the engine runs when you log on, and a trusted add-in folder for Excel. Uninstall removes both.

This website

This website sets no cookies and loads no outside fonts or scripts. It is hosted on GitHub Pages, so GitHub sees your IP address when you open it. The home page also asks GitHub's public API for the latest release's SHA-256, and the download button takes the file from GitHub.

Cookies, and why there is no cookie banner. This website sets no cookies at all, and it saves nothing in your browser: no cookie, no local storage, no session storage, no database in the page. That is the whole cookie policy. A banner asking you to accept cookies exists because the law covers storing or reading things on your own device, and this site does neither, so there is nothing to ask you about. The visit count is a plain image request, which stores nothing. The pane inside Excel does save a few of your own settings on your own PC, which the list above names; those are settings you chose, not a way of following you.

Each page also asks GoatCounter for a tiny image whose address carries the page's address, so he can see how many visits each page gets. Nothing else goes with it, and nothing at all under Do Not Track or Global Privacy Control. The add-in, the pane and the engine never do this.
