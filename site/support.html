Answers first, then a way to ask

Most questions are answered below. Arcas is a free project run by one person, and he answers the rest.

QuestionAnswer
The pane says "Arcas has stopped"

Wait half a minute and press Try again. If that doesn't work, open your Downloads folder, double-click Arcas.exe, then press Try again. It asks you to close Excel, repairs the install, starts the checker and opens Excel again. With an invite kit, double-click install.bat in the kit folder instead.

Windows says "Windows protected your PC"

The app is not code-signed yet, so Windows warns about it. Click More info, then Run anyway. Some PCs show "Open File - Security Warning" instead: click Run. To check the file first, compare its SHA-256 with the one on the release page.

It says "Arcas could not finish. Your Windows account is not an administrator on this PC. Ask the person who looks after your computers to install it for you."

Arcas can only be installed by a Windows account that is an administrator on the PC. To check yours, open Settings, click Accounts, then Your info: an administrator says Administrator under its name.

  1. On a work or school computer, ask your IT team to install it for you, or to make your account an administrator.
  2. On a home computer, sign in to Windows with the account that set the PC up, which is usually an administrator, and double-click Arcas.exe again.
Windows asks to install a certificate

During the install, Windows asks whether to install a certificate from "Anomaly Hunter local CA". Click Yes. It works only for localhost and 127.0.0.1 on this PC, the key that made it is never saved, and uninstall removes it. If you click No, the install stops: run it again and click Yes.

How do I add it to Excel?

After the install, Excel opens a "Start here" workbook with the steps: Home > Add-ins > More Add-ins > SHARED FOLDER > Arcas > Add. You do this once.

How do I update?

Download the latest Arcas.exe and double-click it. If Excel is open, it asks you to close it first. Your AI key stays. The version you have is the Engine line at the bottom of the pane. With an invite kit, double-click install.bat in a newer kit from John.

How do I uninstall?
  1. Press the Windows key and R together.
  2. Copy the line below and paste it into the box that opens.
  3. Press Enter.

"%LOCALAPPDATA%\AnomalyHunter\Arcas.exe" uninstall

It removes the add-in, the checker, its certificate and its files, except the app file itself, which you can then delete. It is not listed in Windows "Installed apps". The privacy page lists what it removes.

With an invite kit, close Excel, run install.bat /u in the kit folder, then delete the kit folder. Like the app's uninstall, it also clears Excel's add-in cache, so other web add-ins may need to be added again.

Where is the log?

In %LOCALAPPDATA%\AnomalyHunter: server.log is this run's, server.log.1 the run before. It can quote values from your sheet, so read it before you paste any of it.

Where is AI help, and what does Remove key do?

Open AI help (optional, free) at the bottom of the pane. Paste a free Google AI key from aistudio.google.com/apikey, or an invite code (it starts with inv_), and click Save key. Then use Ask AI on a flagged row.

Remove key deletes the key and invite code saved in your AnomalyHunter folder; scans and fixes keep working. With an invite kit, also delete invite-code.txt from the kit folder, or installing again turns AI help back on.

It flagged a correct value, or missed one

It can flag correct values and miss mistakes. Move the How hard to look slider: lower for fewer, surer flags; higher to look harder. A suggestion changes nothing until you click Accept; Dismiss skips it.

Is my data private?

A scan runs on your PC and sends nothing. Only Ask AI and Check words with AI send part of your sheet: to Google, or through John's relay to Google if you use an invite code. The privacy page says what is sent.
